# 41st Cloudflight Coding Contest: Data & AI Live Competition

This module documents the solutions and deep learning architectures developed for the official **41st Cloudflight Coding Contest (Data & AI Track)**, held at **CREIC – Regional Centre of Excellence for Creative Industries**, Cluj-Napoca (November 14, 2025).

## 1. Challenge Overview

The live competition required modeling complex ecological parameters for *Birds of Paradise* (BOP) wildlife habitats:

### Level 1: Data Cleansing & Multi-Attribute Compound Ordering
- **Data:** Microclimate observations (`BOP`, `Temperature [°C]`, `Humidity [%]`).
- **Challenges:**
  - Numeric values written as English text words (e.g., `"seventeen"` $\to$ `17`).
  - Corrupted or missing temperature entries.
- **Sorting Criterion:** Descending order by `Temperature [°C]`, ascending by `Humidity [%]`, and ascending by primary key `BOP`.
- **Output:** Space-delimited sequence of sorted BOP identifiers.

### Level 2: Nonlinear Deep Neural Network (ANN) Regression for "Bird Love Score"
- **Data:** Tabular fusion between Level 1 microclimatic indicators (`all_data_from_level_1.in`) and Level 2 environmental metrics (`Vegetation [%]`, `Insects [g/m²]`, `Urban Light [%]`).
- **Heuristic Temperature Disambiguation:** Detection and conversion of temperatures recorded in Fahrenheit ($T > 60$):
  $$T_{\text{Celsius}} = \frac{5}{9} (T_{\text{Fahrenheit}} - 32)$$
- **Model:** Deep Multilayer Perceptron (ANN) with LeakyReLU activations trained to minimize Mean Squared Error (MSE).
- **Output:** CSV files containing predicted compatibility metrics (`Bird Love Score [<3]`) for all test records labeled `missing`.

## 2. Artificial Neural Network (ANN) Architecture

To capture nonlinear feature interactions between habitat metrics and ecological compatibility, a deep feedforward topology was implemented:

```
[Input: 5 Standardized Features]
         │
         ▼
[Dense (128 units)] ──► LeakyReLU(α = 0.01)
         │
         ▼
[Dense (64 units)]  ──► LeakyReLU(α = 0.01)
         │
         ▼
[Dense (64 units)]  ──► LeakyReLU(α = 0.01)
         │
         ▼
[Dense (32 units)]  ──► LeakyReLU(α = 0.01)
         │
         ▼
[Dense (16 units)]  ──► LeakyReLU(α = 0.01)
         │
         ▼
[Dense (4 units)]   ──► LeakyReLU(α = 0.01)
         │
         ▼
[Dense (1 unit)]    ──► Continuous Output (Bird Love Score)
```

### Objective Function & Optimization
- **Loss Function:** Mean Squared Error (MSE):
  $$\mathcal{L}_{\text{MSE}} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2$$
- **Evaluation Metric:** Root Mean Squared Error (RMSE):
  $$\text{RMSE} = \sqrt{\mathcal{L}_{\text{MSE}}}$$
- **Optimizer:** Adam with standard exponential decay rates ($\beta_1 = 0.9, \beta_2 = 0.999$, adaptive learning rate).
